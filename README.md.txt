# FitZone Fitness Management System

A web-based gym management application developed as a college project.

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Features
- Dashboard
- Member registration and management
- Membership tracking
- Payment management
- Attendance tracking

## How to Run
1. Install Python.
2. Open the terminal in the project folder.
3. Install Flask using `python -m pip install flask`.
4. Run the application using `python app.py`.
5. Open the local URL shown in the terminal.

## Project Purpose
This project helps manage gym members, memberships, payments, and attendance through a web application.
